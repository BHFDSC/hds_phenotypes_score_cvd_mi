# Documentation for Files Generated whilst Running Pipelines

## 1. pipeline_run.R

The files listed below are derived during the `pipeline_run.R` script.

### Files saved in the folder 'data'

| File | Description |
|------|-------------|
| `data/interim_data/flowchart_hes_apc.csv` | Flowchart of HES APC data inclusion/exclusion - generated from function `hes_apc_prepare_function.R` in `pipeline_run.R` script |
| `data/interim_data/flowchart_ons_deaths.csv` | Flowchart of ONS deaths data inclusion/exclusion - generated from function `ons_deaths_prepare_function.R` in `pipeline_run.R` script |
| `data/interim_data/hes_apc_excluded_rows.csv` | Rows excluded from HES APC data during preparation - generated from function `hes_apc_prepare_function.R` in `pipeline_run.R` script |
| `data/interim_data/hes_apc_prepared.rds` | Prepared HES APC data - generated from function `hes_apc_prepare_function.R` in `pipeline_run.R` script |
| `data/interim_data/hes_apc_prepared_cips.rds` | HES APC data with CIPS ID - generated from function `hes_apc_generate_cips_function.R` in `pipeline_run.R` script |
| `data/interim_data/ons_deaths_excluded_rows.csv` | Rows excluded from ONS deaths data during preparation - generated from function `ons_deaths_prepare_function.R` in `pipeline_run.R` script |
| `data/interim_data/ons_deaths_prepared.rds` | Prepared ONS deaths data - generated from function `ons_deaths_prepare_function.R` in `pipeline_run.R` script |

### Files saved in the folder 'outputs'

| File | Description |
|------|-------------|
| `outputs/hes_apc_mi_events.csv` | .csv file containing a list of ID's, MI dates and index of MI (i.e. first, 2nd, 3rd etc.) This output is not generated for MI deaths data as a fatal MI can only occur once, negating the need for indexing |
| `outputs/hes_apc_processed.csv` | .csv file containing processed HES APC data with additional columns -- columns of interest include: 'qualify' indicates whether the episode is counted as an MI event by the algorithm, 'mi_date' indicates the date of the MI if qualified, 'mi_count' indicates the number of MI events in the episode, 'terminal_node' indicates the node of the decision tree the episode corresponds to |
| `outputs/ons_deaths_mi_processed.csv` | .csv file containing processed ONS deaths data with additional columns -- columns of interest include: 'qualify' indicates whether the episode is counted as an MI event by the algorithm, 'mi_date' indicates the date of the MI if qualified, 'terminal_node' indicates the node of the decision tree the episode corresponds to |
## 2. run_tests.R

In addition to the above tables generated when the `pipeline_run` script is executed, the optional `run_tests.R` script - used to validate the algorithm - generates the following tables in the folder 'data':

| File | Description |
|------|-------------|
| `data/hes_apc_data/hes_apc_fy_2019.csv`<br>`data/hes_apc_data/hes_apc_fy_2020.csv`<br>`data/hes_apc_data/hes_apc_fy_2021.csv`<br>`data/hes_apc_data/hes_apc_fy_2022.csv`<br>`data/hes_apc_data/hes_apc_fy_2023.csv` | Sample HES APC data with expected outputs columns (e.g. qualify, mi_date, terminal node) removed, split into financial year - generated by `save_ample_data_function.R` |
| `data/ons_deaths_data/ons_deaths_data.csv` | Sample ONS deaths data with expected outputs columns (e.g. qualify, mi_date, terminal node) removed - generated by `save_ample_data_function.R` |
| `data/interim_data/expected_hes_apc_outputs.rds` | File containing the expected output values for the HES APC simulation data including whether the event qualifies as an MI and the associated terminal node -- generated from function `test-validate_hes_apc_function.R` |
| `data/interim_data/expected_ons_deaths_outputs.rds` | File containing the expected output values for the ONS deaths simulation data including whether the event qualifies as an MI and the associated terminal node -- generated from function `test-validate_ons_deaths_function.R` |

The same output files are generated by the `run_tests.R` script as those listed above generated by the `pipeline_run.R` script.
